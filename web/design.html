Design

Design a disordered sequence
Paste a disordered region. This builds a new sequence with a matching inter-residue interaction map, while letting you choose how much of the original amino-acid composition to keep.

Interaction maps come from FINCHES, using the Mpipi and CALVADOS forcefields; sequences are optimized with GOOSE. Every run starts from a GS repeat, so nothing is carried over from the input except what you pin below.
